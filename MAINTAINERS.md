## 2. Review & Release Expectations

- **PR Reviews:** All code changes require at least one approving review from an active maintainer.
- **Architectural Changes:** Any change impacting public APIs, scoring mathematics, or security boundaries requires an approved RFC.
- **Release Authority:** Official version tags and container releases may only be cut by designated release maintainers following the process in [RFC-0010](rfcs/RFC-0010-release.md).
