# Support & Community Channels

## 1. Getting Help

- **Documentation & RFCs:** Refer to [`README.md`](README.md) and [`rfcs/`](rfcs/) for system specifications.
- **GitHub Discussions:** Use GitHub Discussions for questions, architecture design ideas, and community troubleshooting.
- **Issue Tracker:** Use GitHub Issues exclusively for verified bugs and reproducible defects.

---

## 2. Reporting Bugs

When filing a bug report, please provide:
1. Exact commit SHA.
2. Operating system and kernel version (`uname -r`).
3. Toolchain versions (`go version`, `python --version`).
4. Minimal reproducible example or simulator seed (`--seed <number>`).
5. Observed behavior vs. expected behavior.

---

## 3. Security Inquiries

Do **not** report security vulnerabilities via public issues. Refer to [`SECURITY.md`](SECURITY.md) for private reporting channels.
